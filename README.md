# HandLive/.github

The organization profile (`profile/README.md`) and the default community health files for every HandLive repository that has none of its own: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `PULL_REQUEST_TEMPLATE.md`, `ISSUE_TEMPLATE/`. English is the default language; each document has a Vietnamese translation next to it (`*.vi.md`). Licensed under Apache-2.0 (`LICENSE`).
